**BudgetBarkada** is a modern, high-fidelity social budgeting and shared ledger application designed for peer groups (or *barkadas*). It helps users track personal budget goals while securely processing cross-user split expenses, peer-to-peer settlements, and gamified saving challenges.

The project is structured as a monorepo containing two highly decoupled layers:
- **Frontend (V1 UI Context):** A React SPA built with Vite 8, Tailwind CSS v4, and Zustand. It presents a mobile-first, high-contrast, premium interface mimicking modern fintech platforms with persistent global dark/light styling, interactive charting, and real-time social/gamification widgets.
- **Backend (V2 Engine Context):** A strictly typed Node.js/Express API with Prisma ORM connected to a PostgreSQL database. It features an ACID-compliant double-entry ledger database schema, real-time push notification infrastructure, granular privacy controls, and user moderation logic.

### 1. The Core Double-Entry Ledger Engine
At the heart of the system is an ACID-compliant ledger engine configured in the backend's controllers and services. 
- **Atomic Transactions:** Splitting an expense, posting a top-up, or completing a settlement writes to the `transactions` table and creates balancing entries in the `ledger_entries` table. This is executed using atomic `$transaction` blocks in Prisma.
- **Entry Types:** Every transaction creates entries of type `BUDGET_DEDUCTION` (affecting the spender's budget limit), `RECEIVABLE` (representing money owed), or `PAYABLE` (representing money to repay).
- **Ghost Profiles:** Users can track balances with offline friends using *Ghost Profiles* (`isGhost: true`). If a ghost friend signs up later, their profile can be securely merged into a full platform user account.

### 2. Gamification & Engagement Engine
BudgetBarkada implements a sophisticated gamification engine designed to reward positive saving behaviors.
- **Daily Streaks:** Tracks consecutive days users remain under their daily category spending limit.
- **Avatar Frames:** Users earn points by logging transactions, completing challenges, and keeping streaks. Points can be spent to unlock premium CSS-animated border rings (e.g., Bronze, Silver, Gold, Emerald, Fire, and Diamond) that wrap user avatars sitewide.
- **Group Saving Challenges:** Predefined (e.g., Coffee-Free Week, Transport Saver) or custom challenges created by users to compete with friends. The engine handles invite acceptances, daily threshold updates, and automated failure/success states.
- **Badges:** 25+ unique achievements triggered dynamically by system events (e.g., first settlement, 30-day streak, perfect group challenge completion).

### 3. Interactive Social Feed
A social timeline built for accountability:
- **Automated Activity Posts:** Publishes updates when a split is created, a budget milestone is hit, a saving challenge is completed, or a badge is unlocked.
- **Reactions & Comments:** Supports full emoji reactions (👍, 🔥, 👏) and nested comment threads with reply chains and likes.
- **Sidebar Integration:** Feed pages render companion sidebars displaying live budget forecasts and active friends lists.

### 4. Interactive Notifications & Web Push
- **Interactive Alerts:** Custom alerts for friend requests, challenge invitations, and split approvals. Users can approve or reject splits directly from the notification item.
- **Web Push API:** Implements background push alerts using a browser service worker and the backend `web-push` library, allowing notifications even when the browser window is closed.

### 5. Granular User Privacy & Moderation
- **Privacy Toggles:** Users customize settings for profile, debt, and budget visibility (`PUBLIC`, `FRIENDS_ONLY`, `PRIVATE`).
- **Safety Blocks:** Users can block or report accounts to stop friend requests, restrict activity feeds, and hide balance information.

```env
VITE_API_BASE_URL="http://localhost:5000/api"
```

### 3. Database Initialization & Seeding
Set up your PostgreSQL database using Prisma migrations, then run the seeder script to populate the database with badges and avatar frames:

```bash
cd ../backend

# Generate Prisma Client & push schema definitions to the DB
npx prisma db push

npm run seed:gamification
```

### 4. Running the Development Servers
Open two terminal instances to run the services in parallel:

**Terminal 2 (Frontend Client):**

## 🗄️ Database Models Reference

Here is a summary of the PostgreSQL schema managed by Prisma:

- **`User`:** User accounts holding profiles (username, bio, location, display name, avatar URL) and relation pointers to social/ledger nodes.
- **`FriendRequest`:** Manages status (`PENDING`, `ACCEPTED`, `DECLINED`) of peer links.
- **`Friendship`:** Direct link mapping user connections.
- **`FriendProfile`:** Balance tracking profiles mapping registered platform users or offline placeholders (`isGhost: true`).
- **`Category`:** Budget boundaries enforcing user-defined limits.
- **`Transaction`:** Base record detailing ledger events (`EXPENSE`, `SETTLEMENT`, `TOP_UP`).
- **`LedgerEntry`:** Multi-balancing rows linking transactions to users, friend profiles, and values.
- **`FeedPost`:** Posts logged for social interaction (e.g., budget alerts, splits, streaks).
- **`Reaction` / `Comment`:** Comments (with nested replies), and emoji reactions on feed items.
- **`PrivacySettings`:** Settings mapping profile, debt, and budget visibility constraints.
- **`BlockedUser`:** Account restrictions preventing interactions and requests.
- **`Notification` / `PushSubscription`:** Stores read/unread notifications and registration tokens for push devices.
- **`UserGamification`:** Streaks tracker, overall points, and active avatar border settings.
- **`Badge` / `UserBadge`:** Unlocked achievements.
- **`AvatarFrame`:** Collectible CSS-styled user avatar frame items.
- **`Challenge` / `ChallengeParticipant`:** Peer challenges (e.g. coffee-free week, under-budget limits).
- **`PendingTransaction`:** Split request entries awaiting review, approval, or rejection.

## 📡 API Surface Reference

All endpoints are prefixed with `/api`. Protected routes require a valid JWT header (`Authorization: Bearer <token>`).

### 🔑 Authentication (`/auth`)
- `POST /auth/register` — Creates a new account.
- `POST /auth/login` — Authenticates user credentials and returns a JWT.
- `GET /auth/me` — Fetches current user credentials.

### 💰 Categories (`/categories`)
- `GET /categories` — Fetches all user categories.
- `POST /categories` — Creates a category with spending limits.
- `PUT /categories/:id` — Modifies category names and limits.
- `DELETE /categories/:id` — Deletes category entries.

### 📊 Transactions (`/transactions`)
- `GET /transactions` — Fetches complete transactional lists.
- `POST /transactions` — Dispatches new ledger entries (automatically calculates dual-ledger balances).
- `GET /transactions/forecast` — Computes 3-month predictive budgeting trends using historic category spends.
- `GET /transactions/pending` — Lists pending split requests awaiting review.
- `POST /transactions/pending` — Submits a split request for friend approval.
- `POST /transactions/pending/:id/respond` — Approves or rejects a pending split transaction.

### 👥 Friends & Requests (`/friends`)
- `GET /friends` — Lists active friendships and balances.
- `POST /friends/ghost` — Registers a ghost client mapping.
- `POST /friends/ghost/merge` — Merges a ghost account into a registered user account.
- `POST /friends/request` — Sends a friend request.
- `GET /friends/requests` — Lists pending incoming/outgoing requests.
- `POST /friends/request/:id/respond` — Approves or rejects friend requests.

### 📝 Social Activity Feed (`/feed`)
- `GET /feed` — Fetches activities of friends and public feeds.
- `POST /feed/post` — Shares custom feed logs.
- `POST /feed/post/:id/react` — Reacts with emojis.
- `POST /feed/post/:id/comment` — Appends nested comment items.

### 🏆 Gamification (`/gamification`)
- `GET /gamification/status` — Returns streaks, points, and current frame settings.
- `GET /gamification/leaderboard` — Returns point rankings.
- `GET /gamification/badges` — Lists unlocked user badges.
- `GET /gamification/frames` — Lists unlockable avatar frame border options.
- `POST /gamification/frames/:id/equip` — Equips unlocked border frames.
- `GET /gamification/challenges` — Lists active group challenges.
- `POST /gamification/challenges` — Creates new group challenges.
- `POST /gamification/challenges/:id/join` — Accepts challenge invites.

### 🔔 Notifications & Settings (`/notifications` & `/settings`)
- `GET /notifications` — Lists unread notifications.
- `POST /notifications/read` — Marks notification items as read.
- `POST /notifications/subscribe` — Stores push subscription headers for Web Push.
- `GET /settings/privacy` — Fetches active privacy visibility settings.
- `PUT /settings/privacy` — Edits profile, debt, and budget privacy toggles.
- `POST /settings/block` — Blocks target users.
- `POST /settings/report` — Registers user moderation reports.
